# Проекты под НДА

Здесь живут **только публичные описания** проектов, которые выполнялись по договорам
конфиденциальности (NDA) с заказчиками. Код, ТЗ, переписки и внутренние материалы
не публикуются — они остаются в приватных репозиториях и у заказчика.

## Список

| Проект | Роль | Результат (публично) |
|---|---|---|
| Проект CRM / LMS | Участие в требованиях и запуске системы CRM и LMS для заказчика | Собраны и структурированы требования по ролям и процессам, обсуждены доработки CRM |
| «Битрикс Кортекс Мед» | Разработчик / руководитель направления | Медицинская информационная система: доработка модулей, оптимизация, интеграции |
| «Экоторг» | Разработчик / руководитель направления | Связка Битрикс24 и 1С: обмен данными, синхронизация заказов и товаров, отчётные ведомости |

## Как добавлять

Только текстовый `README.md` на проект. Без ссылок на приватные репозитории,
без фрагментов кода, без конкретных цифр и внутренних деталей, если это не согласовано
с владельцем.
