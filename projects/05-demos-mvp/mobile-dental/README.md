# Дентал Клиник — мобильное приложение пациента

Прототип мобильного приложения стоматологической клиники: экраны записи,
истории посещений, напоминаний и личного кабинета пациента в виде
«живого» мокапа на телефоне.

## Стек
- HTML5 + inline CSS/JS, макет в рамке смартфона
- Font Awesome (CDN)

## Что реализовано
- Экраны: главная, запись к врачу, мои посещения, напоминания, профиль.
- Навигация между экранами без перезагрузки.
- Адаптация под мобильные устройства.

## Запуск
Открыть `index.html` в браузере или:
```bash
php -S 127.0.0.1:8090 -t mobile-dental/
```
