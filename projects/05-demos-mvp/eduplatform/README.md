# EduPlatform — интерактивная система тестирования

Демо образовательной платформы: набор предметов, прохождение тестов,
счётчик правильных ответов, результат и прогресс. Английский интерфейс.

## Стек
- HTML5 + inline CSS/JS
- Font Awesome (CDN)

## Что реализовано
- Каталог тестов по предметам.
- Интерактивный проход вопроса с вариантами ответов.
- Подсчёт результата, отображение правильных/неправильных ответов и итоговой оценки.
- Лёгкая анимация переходов.

## Запуск
Открыть `index.html` в браузере или:
```bash
php -S 127.0.0.1:8090 -t eduplatform/
```
