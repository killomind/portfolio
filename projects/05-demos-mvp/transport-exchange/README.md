# Транспортная биржа — демо (PHP + SQLite)

Демо-версия транспортной биржи с геопоиском: грузовладельцы публикуют грузы,
перевозчики — транспорт и задания на поиск. Система сводит их по географии
(радиус и коридор вдоль маршрута) и параметрам (кузов, вес, объём), показывает
экономику рейса, рейтинги и отклики.

Работает на PHP + SQLite (файл `demo.sqlite` создаётся автоматически при первом
запуске и заполняется демо-данными). Без фреймворков. Карта — Leaflet + CARTO.

## Стек

PHP 8 (PDO, SQLite) · JavaScript (ES6+) · Leaflet · SQLite · без фреймворков

## Что реализовано

- **Роли:** перевозчик, грузовладелец, администратор.
- **Карта с геопоиском:** радиус вокруг базы транспорта, коридор вдоль маршрута
  (ломаная), точки погрузки/выгрузки грузов.
- **Поиск и подбор:** тип кузова — первичный жёсткий фильтр, затем вес ≤ грузоподъёмности,
  объём ≤ объёма; радиус/коридор; сортировка по выгодности, расстоянию, ставке.
- **Экономика рейса:** порожняк/крюк (расстояние от базы до точки погрузки),
  стоимость по себестоимости км, ставка, прибыль и маржа.
- **Отклики:** перевозчик откликается на груз, грузовладелец — на транспорт
  (обмен контактами после принятия), история со статусами.
- **Рейтинги и верификация:** автоматический рейтинг, статус верификации владельца.
- **Telegram-бот:** симуляция уведомлений о новых грузах и транспорте (`bot.php?test=1`).
- **Админка:** статистика, пользователи, журнал аудита (`admin.php`).
- **Демо-данные:** 15 машин и 33 груза по городам РФ (тент, рефрижератор, изотерм,
  фургон, борт, контейнер) — ни один фильтр не выдаёт пустую выдачу.

## Запуск локально

```bash
php -S 127.0.0.1:8080 -t .
```

Открыть http://127.0.0.1:8080 (файл `demo.sqlite` создастся автоматически).
