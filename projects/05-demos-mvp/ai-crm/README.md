# AI-CRM — демо

Демо-прототип AI-first CRM/SaaS для бизнеса в сфере услуг. PHP + JSON-база, без фреймворков.
AI-панель эмулирует управление CRM на естественном языке: выполняет действия и отвечает по данным системы.

## Структура

| Файл | Назначение |
|---|---|
| `index.php` | Вход с ролями (кнопки быстрого входа), роутинг |
| `lib.php` | База, авторизация, роли, хелперы |
| `actions.php` | POST-обработчики (PRG-паттерн) |
| `pages/dashboard.php` | Дашборд владельца: выручка, прибыль, загрузка графика |
| `pages/clients.php`, `client_card.php` | Клиенты: список, поиск, карточка с историей визитов |
| `pages/calendar.php` | Календарь записей: день/неделя, перенос, блокировка времени |
| `pages/ai.php` | AI-панель: запросы на естественном языке, лог действий |
| `data/*.json` | Тестовые данные: пользователи, клиенты, записи, услуги, платежи, расходы, блокировки, AI-журнал |
| `style.css` | Общие стили |

## Возможности

- Ролевая модель: владелец (admin), руководитель (manager), оператор (operator), клиент (client)
- Дашборд: выручка, чистая прибыль, загрузка расписания на неделю, последние записи
- Клиенты и календарь: добавление/перенос записей, блокировка времени, свободные окна
- AI-панель (демо): «какая чистая прибыль была на прошлой неделе», «покажи свободные окна на завтра»,
  «перенеси запись клиента», «пришли клиентскую базу на почту», «что с бизнесом на этой неделе» — с логом действий
- Multi-tenant: изоляция данных по ролям/компании

## Запуск локально

```bash
php -S 127.0.0.1:8080 -t .
```

Затем открыть http://127.0.0.1:8080 (демо-доступ — кнопки ролей на странице входа).
