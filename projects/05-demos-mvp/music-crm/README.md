# Music CRM — демо

Демонстрационная копия CRM музыкантов (концерты). PHP + JSON-база, без фреймворков.
Данные тестовые и вымышленные — реальных контактов, телефонов и ссылок VK здесь нет.

## Структура

| Файл | Назначение |
|---|---|
| `index.php` | Карточки музыкантов: список, поиск, фильтры, редактирование, фото-аватарки, вход по паролю |
| `notes.php` | Накопитель заметок (быстрые записи организатора) |
| `data/musicians.json` | База музыкантов (тестовые записи) |
| `data/notes.json` | Заметки (тестовые) |
| `photos/` | Фото-аватарки (демо-картинки) |

## Возможности

- Вход администратора (демо-доступ: логин `admin`, пароль `admin`; кнопка «Войти в демо-версию»)
- Карточки музыкантов: роль, инструмент, статус, приоритет, обещанная дата, заметка
- Поиск и фильтры по статусу/роли/приоритету
- Загрузка/удаление фото-аватарки в редакторе карточки
- Накопитель заметок с пометкой обработки

## Запуск локально

```bash
php -S 127.0.0.1:8080 -t .
```

Затем открыть http://127.0.0.1:8080 (демо-доступ: `admin` / `admin`).

> Замечание: PHP может быть не установлен на этой машине (Mac mini). На MacBook Air
> PHP обычно установлен. См. `~/work-instructions/БРАУЗЕР-И-FTP.md`.
