# ГРК «Горизонт» — карьерный портал (демо-MVP)

Демо-версия карьерного сайта горнодобывающего холдинга под заказ «Разработать карьерный сайт»
(Laravel / ModX) с фриланс-биржи. MVP на PHP + файловая JSON-база, всё на русском, без CMS и MySQL.

**Живое демо:** https://leader-it.com/demo/career-site/

## Что реализовано

- **Интеллектуальный поиск вакансий** с подсказками при вводе и расширенной фильтрацией
  (предприятие, город, регион, направление, график, вахта, переезд, навык, зарплата, опыт, образование).
  Умные рекомендации, когда вакансий не найдено.
- **Карточки вакансий** с полной информацией: описание, обязанности, требования, технологии/стек,
  условия, преимущества, команда, локация, форма отклика, похожие вакансии, кнопка «Поделиться»,
  боковая навигация по карточке.
- **Страницы предприятий** с интерактивной картой, историей, географией, видами найма, вакансиями,
  льготами, FAQ, контактами.
- **Игровые механики:** тест на совместимость (15 вопросов, индекс совместимости, профиль,
  рекомендованные вакансии и предприятия) и карьерные маршруты (5 треков: рабочий, инженер,
  IT, молодой специалист, руководитель).
- **Сторителлинг** — истории сотрудников встроены в ленту вакансий.
- **Админка с модерацией вакансий** (HR-менеджер и администратор).
- **Интеграции с HR-системой «Поток» и HeadHunter** — в демо выбор источника интеграции, откуда
  появилась вакансия/отклик (заглушка реального обмена).
- **Адаптивный мобильный интерфейс**, авторизация по SMS/Telegram (в демо — кнопки быстрого входа
  по ролям + обычная форма логина).

## Демо-доступы (логин совпадает с паролем)

| Роль | Логин | Что видно |
|---|---|---|
| Администратор | admin/admin | модерация, все вакансии, отклики, статистика |
| HR-менеджер | hr/hr | модерация и публикация вакансий, отклики |
| Компания-работодатель | employer/employer (УКК), employer2/employer2 (Волга-Калий) | свои вакансии, заявки на модерацию, отклики |
| Соискатель | candidate/candidate | поиск, отклики, тесты, маршруты, личный кабинет |
| Гость | guest/guest | публичный просмотр без логина |

Публичная часть (вакансии, предприятия, тесты, маршруты) доступна без авторизации.

## Структура

```
career-site/
  index.php      # вход, роутинг ?page=, layout
  lib.php        # JSON-БД, роли, права, хелперы, карта, layout, страница входа
  actions.php    # POST-обработчики (PRG: POST → redirect)
  style.css
  pages/*.php    # home, vacancies, vacancy, enterprises, enterprise,
                 # games, game_route, game_test, moderation,
                 # company_vacancies, responses, my, stats
  data/*.json    # файловая БД с демо-данными (seed лежит в git)
  README.md
```

## Технические ограничения

- Сервер на PHP 7.3 — без `fn()`, `str_contains`, `?->` и фич 7.4+. Только анонимные функции.
- База — JSON-файлы в `data/`, запись через `file_put_contents(..., LOCK_EX)`. Без MySQL.
- Всё на русском. Без внешних CDN и библиотек.

## Развёртывание

- Локально: `php -S 127.0.0.1:8090 -t .`
- На сервере: `https://leader-it.com/demo/career-site/`
- Вложенного git в подпапке нет — файлы коммитятся в общий репозиторий `killomind/leader-it-www`
  (ветка `main`).
- Папка `data/` на сервере должна быть доступна для записи (PHP пишет туда при действиях).
