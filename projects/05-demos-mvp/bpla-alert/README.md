# Оповещения о БПЛА — прототип мобильного приложения

Прототип мобильного приложения системы оповещения о БПЛА: карта оповещений,
уровни угрозы, звуковая тревога (сирена) и настройки.

## Стек
- HTML5 + CSS + JS (один файл, mobile-first), без библиотек и фреймворков

## Что реализовано
- Карта оповещений с отметками.
- Экран оповещений: уровни угрозы, статусы, история.
- Звуковая тревога (сирена) при критичном уровне.
- Настройки приложения (регион, уровень чувствительности и т.п.).

## Запуск
Открыть `index.html` в браузере (без сборки и сервера).
