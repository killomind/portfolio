# KDS Kitchen Display — интеграция с Frontpad

Демо экрана кухни (Kitchen Display System): заказы из онлайн-кассы/API
Frontpad показываются на экране в виде «билетов» с таймером готовности
и автоматическим обновлением.

## Стек
- HTML5 + inline CSS/JS, Chart.js не используется
- Font Awesome (CDN)

## Что реализовано
- Карточки заказов: состав, время поступления, таймер приготовления, цветовая
  кодировка статуса («Новый», «Готовится», «Готово»).
- Автообновление по заданному интервалу; режим демо с мок-данными (`mockMode: true`).
- Адаптивный экран для ТВ/планшета на кухне.

## Запуск
Открыть `index.html` в браузере. Подключение к реальному API Frontpad —
в блоке `CONFIG` в начале скрипта (заполнить `apiUrl` и API-ключ).
