# Интеграция GetCourse ↔ Platron — демо

Интерактивное демо-прототип интеграции платформы онлайн-обучения GetCourse с платёжной
системой Platron: приём платежей, вебхуки, статусы заказов и авто-выдача доступа к продукту.
Один самодостаточный HTML-файл (CSS/JS inline, без внешних CDN), все данные тестовые.

## Возможности

- Цикл «оплата, статус, доступ»: клиент выбирает продукт, оплачивает через Platron, получает доступ
- Имитация вебхуков и статусов оплаты (успех, ошибка, возврат)
- Журнал событий с действиями
- Сценарии: «пройти автоматически», «сбросить», ручной клик по шагам
- Блок обработки ошибок (неуспешная оплата, повторные запросы)

## Запуск

Просто открыть файл в браузере (статический HTML, без сервера).
