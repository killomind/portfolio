# Юлия Гербер — сайт бизнес-тренера по продажам

Демо-макет персонального сайта бизнес-тренера: лендинг с программой
обучения продажам, отзывами, формами записи и контактами.

## Стек
- HTML5 + inline CSS/JS
- Внешние ресурсы: шрифты/стили сайта-прототипа

## Что реализовано
- Главный экран с оффером и кнопками действий.
- Разделы: программы, о тренере, отзывы, записи на вебинар/консультацию.
- Мобильная адаптация и якорная навигация.

## Запуск
Открыть `index.html` в браузере или:
```bash
php -S 127.0.0.1:8090 -t juliagerber/
```

## Примечание
Демо повторяет структуру персонального сайта тренера; часть оформления
подгружается из внешних источников прототипа — при офлайн-просмотре
некоторые блоки могут отображаться без стилей.
