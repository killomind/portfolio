# SupplyCRM AI — CRM для поставок с ИИ-ассистентом

Демо (MVP) CRM для управления поставками: сделки, клиенты, документы,
финансы, календарь и встроенный ИИ-помощник, отвечающий на вопросы
по данным системы.

## Стек
- HTML5 + CSS + JS (один файл), без библиотек и фреймворков
- Имитация ИИ-ассистента (сценарии ответов по данным CRM)

## Что реализовано
- Дашборд со сводкой по сделкам, поставкам и финансам.
- Сделки, клиенты, документы, задачи, поставки, финансы, календарь, команда.
- AI-анализ сделок и AI-помощник: ответы на вопросы по сделкам,
  документам, задачам, поставкам, финансам и срокам.
- Настройки и роли пользователей.

## Запуск
Открыть `index.html` в браузере (без сборки и сервера).
