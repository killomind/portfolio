# inventory-qr-scanner — Сканер QR-кодов для учёта инвентаря

Прототип мобильного приложения Android для учёта инвентаря через сканирование QR-кодов.
Исходники живут в публичном репозитории — в портфолио только ссылки и описание.

## Что это

Приложение для мастера/сотрудника: сканирует QR-код с единицы оборудования и фиксирует
выдачу/обслуживание. Работает офлайн, данные синхронизируются (в перспективе — с 1С).
Подробное описание сценария — в кейсе на сайте Лидер·Айти (раздел мобильной разработки).

## Стек

- Kotlin, Jetpack Compose (Material 3)
- Android SDK 36 (minSdk 23), Java 11
- ZXing (zxing-android-embedded 4.3.0) — распознавание QR-кодов

## Что реализовано

- Главный экран с кнопкой запуска сканера
- Экран сканера: камера, распознавание QR, возврат результата (без сохранения)
- Разрешение на камеру в манифесте

## Запуск

Открыть папку в Android Studio, дождаться синка Gradle, запустить на устройстве/эмуляторе.
