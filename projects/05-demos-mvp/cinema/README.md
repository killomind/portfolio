# Кинозал — бронирование мест с выбором сеанса

Одностраничное демо (HTML + CSS + JS): выбор киносеанса и интерактивное
бронирование мест в зале с мгновенной подсветкой занятых и выбранных.

## Стек
- HTML5 + inline CSS/JS, без библиотек и фреймворков
- Font Awesome (CDN)

## Что реализовано
- Список сеансов с фильмом, залом и временем.
- Схема зала: ряд/место, занято — свободно — выбрано, подсветка при наведении.
- Подсчёт стоимости выбранных мест и предпросмотр брони.

## Запуск
Открыть `index.html` в браузере или:
```bash
php -S 127.0.0.1:8090 -t cinema/
```
