# Автосервис 360

Демо-версия (MVP) платформы управления сетью автосервисов с несколькими филиалами.

## Возможности

- Личные кабинеты по ролям: администратор сети, руководитель филиала, мастер-приёмщик, механик, клиент.
- Заказ-наряды: создание, состав работ и запчастей, автоматический расчёт стоимости, смена статусов с историей (новая заявка → подтверждена → диагностика → в ремонте → готов → выдан).
- Онлайн-запись через календарь со свободными слотами по филиалам и датам.
- База клиентов, автомобилей и история обслуживания каждой машины.
- Склад: остатки по филиалам, приход / списание / перемещение деталей, контроль минимального остатка.
- Справочник работ и цен (категории, нормо-часы).
- Отчёты: выручка, средний чек, динамика по месяцам, разбивка по статусам и филиалам.

## Технологии

- Чистый PHP 7.4+ (без фреймворков), одна точка входа `index.php`.
- Файловая база данных — JSON-файлы в `data/` (без MySQL). Подходит для демо и малой нагрузки.
- Без внешних CDN и библиотек: весь CSS и JS локальные.

## Демо-доступы

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | admin | admin |
| Руководитель филиала | manager | manager |
| Мастер-приёмщик | advisor | advisor |
| Механик | mechanic | mechanic |
| Клиент | client | client |

Войти можно кнопками быстрого входа на странице логина.

## Развёртывание

Требуется любой хостинг с PHP 7.4+ (поддерживаются PHP 8.x). Скопировать содержимое папки на сервер — больше ничего не нужно. Папка `data/` должна быть доступна для записи (по умолчанию уже создана и наполнена демо-данными).

Локально:

```bash
php -S 127.0.0.1:8000 -t .
```

Открыть http://127.0.0.1:8000/

## Структура

```
index.php      — вход, роутинг, layout
lib.php        — слой JSON-БД, авторизация, хелперы
actions.php    — обработка форм (PRG-паттерн)
style.css      — все стили
pages/         — страницы (dashboard, orders, order_edit, order_view, calendar, clients, cars, warehouse, catalog, employees, reports)
data/*.json    — файловая база с демо-данными
```
