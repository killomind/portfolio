# Платёжный контур — демо (PHP)

Демо-версия платёжно-кассового контура торговой платформы (мебель и интерьеры):
финансовый модуль, интеграция ЮKassa, облачная ККТ. Работает на PHP + JSON-файлы.

## Стек (в боевом проекте)

Laravel 11 · PostgreSQL 16 · Redis. В демо — PHP 7.3 + файловая JSON-БД.

## Что демонстрирует

- **Регистр проводок (двойная запись):** каждый платёж порождает три проводки
  (Дт 51/Кт 62, 62/90, 90/68), возвраты — сторно. Контроль: остаток на счёте 51
  = оплаты − возвраты.
- **Идемпотентность webhook:** уникальный ключ события + два транзакционных шага
  («принято» → «проведено»). Повторная доставка не дублирует проводки; сбой
  посреди обработки откатывает транзакцию, повтор обрабатывается как уже принятый.
- **ЮKassa:** приём платежей, webhooks, полные и частичные возвраты.
- **ККТ:** чек в облачную кассу после оплаты и после возврата.
- **Снимки заказов и реестр обязательств:** фиксация состояния на момент оплаты,
  закрытие обязательства при успешной оплате.
- **Автотесты:** инварианты целостности (расчёты, идемпотентность, откат, баланс).

## Как запустить

```bash
php -S 127.0.0.1:8090 -t .
```

Открыть http://127.0.0.1:8090/

## Демо-логины

| Роль | Логин | Пароль | Доступ |
|---|---|---|---|
| Финансовый директор | admin | admin | всё |
| Бухгалтер | accountant | accountant | проводки, возвраты, касса, снимки, обязательства, тесты |
| Оператор | operator | operator | заказы, платежи, webhook-симуляция |
| Техподдержка | support | support | webhook-журнал, тесты |

## Сценарии для демонстрации

1. **Платёж за заказ:** раздел «Заказы» → «Создать платёж» → «Webhook: оплачен».
   Проводки появятся в «Регистре проводок», чек — в «Касса (ККТ)».
2. **Идемпотентность:** в «Платежи ЮKassa» у оплаченного платежа нажать «Повторный webhook»
   — в журнале событие помечается «Дубликат», новые проводки не создаются.
3. **Сбой посреди обработки:** у ожидающего платежа «Сбой + повтор» — транзакция откатывается,
   повторная доставка обрабатывается заново без дублей.
4. **Возврат:** у оплаченного платежа «Частичный возврат» / «Полный возврат» —
   сторно-проводки и чек возврата.
5. **Тесты:** раздел «Автотесты» → «Запустить проверки» — все инварианты сходятся.
