# Турбаза «Белая Гора»

Демо-версия (MVP) веб-сервиса онлайн-бронирования домиков на турбазе: каталог жилья,
календарь доступности, выбор дат и гостей, автоматический расчёт цены по сезонам,
оформление брони с онлайн-оплатой, личные кабинеты по ролям и админка для управления.

## Возможности

- Каталог домиков: фото, описание, удобства, вместимость, стоимость по сезонам.
- Календарь доступности по домикам и датам (свободно / занято), мини-календарь в карточке домика.
- Онлайн-бронирование: выбор дат и количества гостей, доп. услуги (баня, прокат, завтраки),
  детальный расчёт стоимости с учётом сезонных коэффициентов.
- Онлайн-оплата и «отправка» подтверждения брони на e-mail гостя.
- Статусы брони: новая → подтверждена → оплачена → заселение → выезд (с историей изменений).
- Роли: администратор базы, менеджер по бронированию, администратор приёма, горничная, гость.
- Админка: добавление и редактирование домиков, доп. услуг и сезонов, ведение гостей.
- Отчёты: оплаты по месяцам, загрузка домиков, выручка по домикам и статусам.
- Адаптивная вёрстка для мобильных устройств.

## Технологии

- Чистый PHP 7.3+ (без фреймворков), одна точка входа `index.php`.
- Файловая база данных — JSON-файлы в `data/` (без MySQL).
- Без внешних CDN и библиотек: только Google Fonts, весь CSS и JS локальные.

## Демо-доступы

| Роль | Логин | Пароль |
|---|---|---|
| Администратор базы | admin | admin |
| Менеджер по бронированию | manager | manager |
| Администратор приёма | operator | operator |
| Горничная | housekeeper | housekeeper |
| Гость | client | client |

Войти можно кнопками быстрого входа на странице логина.

## Развёртывание

Любой хостинг с PHP 7.3+. Скопировать содержимое папки на сервер. Папка `data/` должна быть
доступна для записи. Локально:

```bash
php -S 127.0.0.1:8000 -t .
```

## Структура

```
index.php      — вход, роутинг, layout
lib.php        — слой JSON-БД, авторизация, роли, хелперы расчёта
actions.php    — обработка форм (PRG-паттерн)
style.css      — все стили
pages/         — dashboard, catalog, cottage, booking, booking_view, bookings, calendar, services, guests, settings, reports
data/*.json    — файловая база с демо-данными
```
