# FlexQC — контроль качества флексоформ (демо)

Демо-версия (MVP) системы автоматизированного визуального контроля флексоформ
и печатных форм на просветном столе с камерой на сервоприводе и ML-детекцией дефектов.

Домен: изготовление флексоформ (фотополимерных печатных форм) из трафаретов и
фотоформ. Сейчас контроль качества выполняется вручную на просветных столах —
это занимает много времени. Демо показывает, как выглядит автоматизированное
рабочее место оператора ОТК.

Адрес: https://leader-it.com/demo/flexqc/

## Демо-доступы (логин/пароль, либо кнопки быстрого входа)

- `operator/operator` — Контролёр ОТК: рабочее место, запуск скана, журнал
- `engineer/engineer` — Инженер по качеству: модель распознавания, справочник дефектов
- `manager/manager` — Руководитель ОТК: журнал, аналитика, добавление форм
- `director/director` — Директор производства: сводка и аналитика
- `admin/admin` — Администратор: сотрудники + всё остальное

## Что видно в демо

- Рабочее место: просветный стол, снимок формы с зонами печати, разметка дефектов
  с координатами; запуск скана одним кликом.
- Автоматический вердикт по регламенту ОТК: критический дефект — брак,
  существенный — доработка, только незначительные — годна.
- Справочник дефектов флексоформ: воздушные пузыри, включения, царапины,
  утолщённые/потерянные растрные точки, кратеры, пикхолы, загрязнения.
- Журнал проверок с разметкой каждого скана.
- Аналитика: выход годных, структура дефектов, динамика по дням, по операторам.
- Страница модели: mAP/recall/precision, точность по классам дефектов.

## Стек

PHP 7.3-совместимый код, файловая JSON-БД (data/*.json), один общий style.css,
Google Fonts (Inter). Без внешних библиотек и CDN.

## Структура

| Файл/папка | Назначение |
|---|---|
| `index.php` | Точка входа: сессия, роутинг `?page=`, вход, layout |
| `lib.php` | JSON-БД, роли, хелперы, SVG-визуализация стола, layout, страница входа |
| `actions.php` | POST-обработчики (PRG: POST → redirect) |
| `pages/*.php` | Страницы: dashboard, scan, checks, check_view, forms, defects, reports, models, employees |
| `data/*.json` | Seed-данные: пользователи, формы, дефекты, проверки, модель |
| `style.css` | Все стили |

## Запуск локально

```bash
php -S 127.0.0.1:8090 -t .
```
