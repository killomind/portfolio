# Интерактивное тестирование Tovarum.ru

Демо-версия процесса ручного тестирования веб-сервиса Tovarum.ru:
симуляция проверки ключевых сценариев на основе реального интерфейса
с пошаговым журналом результатов, анимацией курсора и фиксацией найденных багов.

## Стек
- HTML5 + CSS + JS (один файл), без библиотек и фреймворков

## Что реализовано
- Автодемонстрация тестовых сценариев (15 шагов): загрузка страницы,
  переход по категориям, формы регистрации и объявлений, мобильная версия,
  поиск, чат, корзина, переключение языка, геолокация, виджеты.
- Журнал проверки: каждый шаг с вердиктом (пройдено/баг/инфо) и описанием.
- Найденные баги: отсутствие валидации длины пароля, нет индикатора загрузки
  фото, перекрытие меню баннером на узких экранах, корзина без уведомления
  о входе.
- Управление: автозапуск/пауза, пошаговый проход, сброс.

## Запуск
Открыть `index.html` в браузере (без сборки и сервера).
