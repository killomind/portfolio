# СметаПро — система подготовки смет (монтажно-инженерная компания)

Демо (MVP) системы подготовки смет для монтажно-инженерной компании:
пошаговое формирование сметы из спецификации, подбор товаров/работ,
контроль соответствия и итоговый документ.

## Стек
- HTML5 + CSS + JS (один файл), без библиотек и фреймворков
- Google Fonts (типографика)

## Что реализовано
- Пошаговый мастер формирования сметы (5 шагов).
- Спецификация: позиции с характеристиками, количеством и единицами.
- Подбор товаров и работ из каталога под позиции спецификации.
- Контроль соответствия позиций (подобран товар/работа, код каталога).
- Итоговая смета с формированием документа и подсчётом.

## Запуск
Открыть `index.html` в браузере (без сборки и сервера).
