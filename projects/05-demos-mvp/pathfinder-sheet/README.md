# Pathfinder 1e — лист персонажа (настольная RPG)

Hobby-проект: интерактивный лист персонажа для настольной ролевой игры
Pathfinder 1st Edition. Персонаж «Юдард Ари».

## Стек
- HTML5 + inline CSS/JS, без библиотек

## Что реализовано
- Характеристики, модификаторы, навыки, инициатива, КЗ, хиты.
- Расчёт бонусов/Штрафов и автообновление производных параметров.
- Вкладки: характеристика, бой, способности, снаряжение, заклинания.

## Запуск
Открыть `index.html` в браузере или:
```bash
php -S 127.0.0.1:8090 -t pathfinder-sheet/
```
