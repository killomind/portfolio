# Блог на чистом PHP (JSON + пагинация)

Движок блога корпоративного сайта: статьи хранятся в JSON, выводятся
PHP-страницей с пагинацией и оформлением в стиле основного сайта.

## Стек
- PHP 7+, без фреймворков и внешних библиотек
- Данные — `blog_data.json` (262 статьи на боевом сайте; здесь — выборка 12)
- CSS/JS inline в странице

## Что реализовано
- `blog.php` — вывод статей из JSON с сортировкой по дате и пагинацией
  `?page=N` (12 статей на страницу + кнопки «В начало/В конец»).
- `blog_parser.php` — генератор `blog_data.json`: парсит HTML-экспорт
  Telegram (`messages.html`) через DOMXPath, нормализует даты/timestamp,
  объединяет с дополнительными статьями и сортирует по времени.
  Запуск: `php blog_parser.php`.

## Запуск
```bash
cd leader-it-blog
php -S 127.0.0.1:8090
# открыть http://127.0.0.1:8090/blog.php
```
