# Просмотрщик экспорта Skype (потоковый, без загрузки всего файла)

Инструмент, который я сделал для себя: смотреть личный экспорт переписок Skype
(`messages.json` на десятки МБ) как обычный чат — без загрузки всего JSON в память.

## Стек
- PHP 7.4+
- [halaxa/json-machine](https://github.com/halaxa/json-machine) — потоковый парсинг
  JSON (читает только нужный указатель `/conversations`)
- HTTP Basic Auth через переменные окружения

## Что реализовано
- `index.php` — отдаёт беседы постранично (10 на страницу), читая файл потоком
  через `Items::fromStream` с JSON-pointer; память при этом почти не растёт.
- Поиск по названию беседы, участникам и тексту сообщений (без дозагрузки файла).
- Разбор системных событий Skype: добавление участников, смена темы, звонки,
  открытие/скрытие истории.
- Определение автора = владельца экспорта из корня JSON (`userId`).
- Логин/пароль — из `VIEWER_USER` / `VIEWER_PASS` (по умолчанию `demo`/`demo`).
- `messages.json` — демо-выгрузка с обезличенными беседами: подставьте свой экспорт.

## Запуск
```bash
composer install
php -S 127.0.0.1:8090
# открыть http://127.0.0.1:8090/ (логин demo / пароль demo)
# свой экспорт из Skype → файл messages.json в этой папке
```

## Примечание
Демо-данные полностью вымышленные. На реальном экспорте понадобится настройка
`JSON_FILE` и смена дефолтных учётных данных.
