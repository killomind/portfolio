# Генератор квитанции ПД‑4 с QR‑кодом (ГОСТ)

PHP-скрипт формирует бланк «Извещение / Квитанция» ПД‑4 для ИП и PDF
с QR‑кодом по требованиям обязательных платежей. Реквизиты заполняются
через форму и подставляются в строку QR (стандарт `ST00012`).

## Стек
- PHP 7.3+, без фреймворков
- [TCPDF](https://github.com/tecnickcom/TCPDF) для генерации PDF и QR (GOST)

## Что реализовано
- Форма для ввода реквизитов получателя и плательщика.
- Сборка QR‑строки ГОСТ: Name, PayeeINN, KPP, OGRNIP, OKTMO, KBK, UIN,
  PersonalAcc, BankName, BIC, CorrespAcc, Sum, Purpose.
- Генерация A4-страницы «ИЗВЕЩЕНИЕ» + «КВИТАНЦИЯ» и QR‑кода 100×100 мм.
- Значения по умолчанию — демо-пример (заменить своими реквизитами).

## Запуск
```bash
composer install
php -S 127.0.0.1:8090
# открыть http://127.0.0.1:8090/
```

## Примечание
Скрипт не содержит реальных реквизитов: имена, ИНН, счета и СНИЛС
заменены демо-значениями.
