# Текстовый накопитель (подготовка данных к прочтению)

Внутренний инструмент для себя и команды: собирает длинные тексты из разных
источников (статьи, дайджесты, переписки), чистит их по правилам и разбивает
на страницы по количеству символов, чтобы удобно читать с телефона.

## Стек
- PHP 7+, без фреймворков и БД (данные — JSON-файлы)
- Сессионная авторизация, учётные данные из переменных окружения

## Что реализовано
- Вкладки с текстами (JSON-файлы в `tabs/`), новая вкладка из интерфейса.
- Вставка текста с автосохранением (base64-кодирование при отправке).
- Два режима чистки `cleanText()`: «Обычный» (добавляет точки в конец строк
  без пунктуации) и «Книжный» (убирает висячие дефисы и переносы).
- Пагинация по числу символов (`chunk_size` / `max_block`): длинное сообщение
  режется на фрагменты, страница не превышает заданный размер.
- Оценка времени чтения (~N мин по 1000 символов в минуту) для вкладки и страницы.
- Клик по карточке — копирование исходника; «Скопировать все» — вся вкладка.
- Корзина: удаление сообщений/вкладок с возможностью восстановления вручную,
  одинаковые настройки постранично (применяются из `.pagination_config`).
- Авторизация: `READ_PREP_USER` / `READ_PREP_PASS` (по умолчанию `demo`/`demo`).

## Запуск
```bash
php -S 127.0.0.1:8090
# открыть http://127.0.0.1:8090/ (логин demo / пароль demo)
```

## Примечание
`tabs/demo.json` — обезличенный пример данных. Реальные вкладки лежали
внутри компании и в репозиторий не переносятся.
