# Защищённая отчётная страница для клиента

Пример механизма показа отчётов заказчику: статичная HTML-страница
отчёта закрыта HTTP Basic-авторизацией и отдаётся PHP только после успешного
входа. Данные отчёта в примере обезличены — это шаблон/механика, а не
реальный клиентский документ.

## Стек
- PHP 7+, без фреймворков и БД
- HTTP Basic Auth через `PHP_AUTH_*`

## Что реализовано
- `index.php` — проверяет логин/пароль (берёт из переменных окружения
  `REPORT_USER` / `REPORT_PASS`, по умолчанию `demo`/`demo`), при ошибке
  возвращает 401, при успехе подключает `report.html`.
- `report.html` — пример отчёта о трудозатратах по дням с итогами.
- Защита: файл `report.html` не лежит в открытом доступе (закрыт через
  `.htaccess`, см. `reports/crm/.htaccess` исходного проекта).

## Запуск
```bash
REPORT_USER=client REPORT_PASS=secret php -S 127.0.0.1:8090
# открыть http://127.0.0.1:8090/ → браузер запросит логин/пароль
```
