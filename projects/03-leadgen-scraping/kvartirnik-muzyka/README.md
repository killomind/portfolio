# kvartirnik_muzyka

Поиск музыкантов и площадок во ВКонтакте для квартирников: разбор сохранённых страниц
(HTML/PDF), классификация ролей и типов страниц, сбор базы контактов в CSV.

## Стек

- Python 3.9+ (основные режимы — без внешних зависимостей; `requests` нужен только для API-режима)
- Разбор HTML: `html.parser` (stdlib), PDF: Swift + PDFKit (вспомогательный скрипт `pdf_text.swift`)
- Официальный VK API (режим по токену): followers, subscriptions, wall-упоминания, участники групп

## Что реализовано

- Извлечение ссылок ВК из сохранённых страниц: обычные `<a href>`, `vk.com/...`, `m.vk.com/...`,
  относительные `/id123456`, а также ВК-упоминания в тексте постов `[id123456|Имя]`, `[club123|Имя]`.
- Из PDF дополнительно: ссылки `/URI` (в т.ч. hex-кодированные) и распознанный текст.
- Классификация ссылок: `profile` (человек) / `group` (группа/сообщество) / `other` (служебное).
- Пометка музыкальных ссылок по словарю ключевых слов; склейка дублей между файлами
  с подсчётом «в N файлах» (показатель значимости).
- Анализ ролей и типов страниц (`--roles`): вокалист, гитарист, барабанщик, диджей и т.д.,
  а также типы сообществ: музыкальное сообщество, бар/кафе/площадка, студия, вечеринки.
  Словари-признаки `ROLE_RULES` / `COMM_RULES` легко расширяются.
- База контактов CSV (кто уже контактирован → `--only-new`), результат в `vk_links.csv`
  (UTF-8 BOM, открывается в Excel).
- API-режим через токен VK: сбор подписчиков, подписок, упоминаний со стены и участников групп.

## Запуск

```bash
python3 vk_links.py                       # все ссылки из папки html/
python3 vk_links.py --music --only-new    # новые музыкальные, кому ещё не писал
python3 vk_links.py --roles               # кто такой и что за страница
python3 vk_links.py <путь/x.html>         # разобрать один файл
python3 vk_links.py --folder <путь>       # другая папка со страницами
python3 vk_links.py --out <файл>          # куда сохранять результат
```

Страницы сохраняются из браузера («Веб-страница, полностью» или PDF) в папку `html/`.
Ссылки, найденные скриптом, всегда проверяются вручную.

## Приватность
